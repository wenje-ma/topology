## 2. 写作模板（必须与 `functional-analysis\cn\homework\week1.md` 完全一致）

逐条对照模板执行：

**2.1 文档标题**：`# weekN`（小写 week + 数字）。

**2.2 文首引用区（blockquote）**：正文开始处，把本份解答实际用到的**全部结论**逐字抄出，每条一行 `> `，格式为

```
> **< 类别> : < 名称> **<br>< 该结论完整内容，逐字> 
```

- 类别沿用模板：`基础知识: …`（教材外的标准事实）、`定义 1.1.1 (名称)`、`定理 …`、`命题 …`、`例 …`、`引理 …`。编号沿用教材/题集/笔记的编号（如 `定义 3.1 (拓扑空间)`、`定理 5.1 (紧空间连续像紧)`），并**在条目末尾标注出处**（教材 /《拓扑学》(原书第2版) §X /《基础拓扑学》(修订版) 第X章 / 题集 §X，含页码）。
- **编号列举分行（重要）**：条目内**开头的设定句、每个编号条件、最后的结论句各自独立成行**，以 `<br>` 分隔；每个编号条件以英文分号 `;` 结尾（若后接结论句，则末项以英文逗号 `,` 结尾再换到结论行）。两种典型排版都要照抄：
  1. 有总结句：`…而且满足下面条件:<br>(i) …;<br>(ii) …;<br>(iii) …,<br>则称 …`（见 `定义 1.1.1 (度量空间)`）。
  2. 无总结句、逐条下定义：`设 ….<br>(i) 如果…, 就称 …;<br>(ii) 如果…, 就称 …`（见 `定义 1.3.1 (正交系与标准正交系)`）；此时每个编号项各自定义自己的术语，不额外加「则称」行。
  解答与正文中的列举同样按此分行。
- **标号规则**：文献中已有标号的结论，**采用文献标号**（如教材 `定理 3.1`、`《拓扑学》(原书第2版)` `定理 34.1`、`《基础拓扑学》(修订版)` `定理(4.1)`、题集 `§X`）。文献未给标号的（如讲义只给定理编号、不给定义编号），**自编标号**。
- **引用区排列顺序**：① 基础知识类条目在前（无编号，起复习作用）；② 其后为书中结论（带编号条目）；③ 带编号条目按**序号升序**排列（如 1.2.1 排在一切 1.1.x 之后），**不按解答的引用先后**；④ 同序号的条目按类别排序：定义 > 说明 > 引理 > 命题 > 定理 > 推论 > 断言 > 猜想 > 注 > 例子 > 证明 > 习题。
- **自编号方案（已确认）**：沿用该结论所属来源的序号体系，编成它本应在该来源序列中出现的位置，保证整体能按升序排序。例如：出自教材 §K 的自编号为 `K.n`；出自《拓扑学》(原书第2版) 的自编号为 `M.n`（M 为章/节，n 为自增）；出自《基础拓扑学》(修订版) 的自编号为 `(c.n)`；出自题集 §S 的自编号为 `S.n`。自编号不得与文献既有编号冲突。
- 该区是解答可引用的**结论库**：解答中只能引用这里列出的条目。

**2.3 分隔**：引用区之后一条 `---`。

**2.4 每题结构**：
- `## < 题号> `（题号沿用模板的教材式编号；拓扑作业沿用现有 `习题一/习题二/…` 编号即可）。
- 该 `##` 标题下**完整写出题目文本（即抄题）**。
- 然后 `### 解答 < 题号> `，接解答。

**2.5 解答体写法**：
- 引用区条目在文内**用全称加粗引用**（类别 + 序号 + 名称），格式 `由**基础知识: 凹函数过原点的次可加性**` / `依据**定义 1.1.1 (度量空间)**`；**不得只说序号**（不得只写「由定义 1.1.1」或「由定理 3.1」之类）。并把该结论的相关内容**当场写出**（即显式写出所引结论）再应用，例如「由**基础知识: 实数绝对值的三角不等式**，$\left|a+b\right|\le\left|a\right|+\left|b\right|$，故……」。
- **相邻两句可推导**：后一句必须能由前一句（或其紧跟的前几句）逻辑推出。这是硬性检查。
- 用加粗标签分步：`**第一步: …**`、`**第二步: …**`，小题用 `**(i)**`、`**(ii)**`、`**(a)**`、`**(b)**` 等。
- 解答末尾 `$\blacksquare$`。
- 某些题解后可有尾部 `> ` 注（思路/技巧），风格同模板（如「> 构造思路: …」）。

**2.6 完全依据参考文献，禁止凭记忆造结论**：每一条出处必须先在该教材文本中实际核验存在后再引用；找不到出处的结论改为**自证**并明确标注「（未在三本教材中直接找到，自证）」。

**2.7 保留核心论证**：题目本身就是要证的标准定理（如巴拿赫不动点、原像与并/交交换）不能引用同一定理；具体空间/构造的验证与计算（谢尔宾斯基映射枚举、弗斯滕伯格/戈洛姆/基尔希三拓扑、删齿梳、半范数生成 TVS 且局部凸、$E\setminus H$ 道路连通⟺$H$ 非闭、里茨定理应用、凸集无界出半直线、商空间具体粘合识别、不动点类习题）的核心推导必须完整保留，只能靠删除冗余复述瘦身。

**2.8 结构与格式**：不改动题目文本；中文 + LaTeX；块内换行用 `<br>`；就地更新原文件。LaTeX 混排细节：数学模式内嵌中文时，中文置于 `\text{...}` 内（内部**不含首尾空格**），与相邻数学符号之间用 `\;` 间隔——如 `H=\left\{f\;\text{是}\;\mathbb R\;\text{上勒贝格可测函数:}\int_{\mathbb R}\left|f\left(t\right)\right|^2\omega\left(t\right)\,\mathrm dt< \infty\right\}`，而**不是** `f\text{ 是 }\mathbb R\text{ 上…}`（即中文与数学符号之间用 `\;`，`\text{}` 内不留首尾空格）。

**2.9 标点符号全用英文**：全文使用英文（ASCII）标点，如 `, . : ; ( ) ! ? - =`；禁止全角中文标点（`，。：；（）！？、`）。LaTeX 数学内标点本身即 ASCII。模板（functional-analysis week1）通篇即此风格。

**2.10 全文不出现任何英文人名**：所有人名一律用中文，不得出现英文人名。三本教材在文内只以中文指代（见第 1 节：教材 /《拓扑学》(原书第2版) /《基础拓扑学》(修订版)）；定理/人名用通行中文译名（乌雷松、巴拿赫、豪斯多夫、谢尔宾斯基、弗斯滕伯格、戈洛姆、基尔希、吉洪诺夫、贝尔、里茨、柯西、施瓦茨、哈恩、施坦豪斯、绍德、利普希茨 等）。
