**定理2.14** $|\mathbb{R}^\mathbb{R}| = |\mathcal{P}(\mathcal{P}(\mathbb{N}))|$。因此 $\mathbb{R}$ 上的函数代表了第三种无穷。

*证明。*首先注意到有一个简单的不等式：

$$|\mathcal{P}(\mathcal{P}(\mathbb{N}))| = |\mathcal{P}(\mathbb{R})| = |2^\mathbb{R}| \leq |\mathbb{R}^\mathbb{R}|.$$

另一方面，我们可以通过交错小数数字构造单射 $i : \mathbb{R}^2 \to \mathbb{R}$。由于函数 $f : \mathbb{R} \to \mathbb{R}$ 是一种特殊的关系 $f \subset \mathbb{R} \times \mathbb{R}$，我们有：

$$|\mathbb{R}^\mathbb{R}| \leq |\mathcal{P}(\mathbb{R}^2)| = |\mathcal{P}(\mathbb{R})|,$$

因此由施罗德-伯恩斯坦定理得 $|\mathbb{R}^\mathbb{R}| = |\mathcal{P}(\mathcal{P}(\mathbb{N}))|$。

理解 $|\mathbb{R}^2| = |\mathbb{R}|$ 的另一种方式是 $|\mathbb{N} \times 2| = |\mathbb{N}|$，从而

$$|\mathbb{R}^2| = |\mathcal{P}(\mathbb{N}) \times \mathcal{P}(\mathbb{N})| = |\mathcal{P}(\mathbb{N} \times 2)| = |\mathcal{P}(\mathbb{N})| = |\mathbb{R}|.$$

**连续统假设。**利用选择公理，可以证明对任意两个集合 $A$ 和 $B$，要么 $|A| \leq |B|$，要么 $|B| \leq |A|$。

是否存在集合 $A$ 使得 $|\mathbb{N}| < |A| < |\mathbb{R}|$？现在已知这个问题无法用集合论的公理来回答（假设这些公理本身是一致的）。一些逻辑学家论证连续统假设显然是错的（科恩、武丁），而另一些人论证它必然是对的（武丁）。
