# 2 集合论基础

## 集合论的公理

- **公理 I（外延性）** 一个集合由其元素决定。也就是说，如果 x ∈ A ⇒ x ∈ B，反之亦然，那么 A = B。
- **公理 II（特称化）** 如果 A 是一个集合，那么 {x ∈ A : P(x)} 也是一个集合。
- **公理 III（配对）** 如果 A 和 B 是集合，那么 {A, B} 也是集合。由这条公理和空集 = 0，我们可以构造 {0,0} = {0}，称之为 1；也可以构造 {0,1}，称之为 2；但还不能构造 {0,1,2}。
- **公理 IV（并集）** 如果 A 是一个集合，那么 ∪A = {x : ∃B, B ∈ A & x ∈ B} 也是一个集合。由这条公理和配对公理，我们可以构造 ∪{A,B} = A ∪ B。于是可以定义 x⁺ = x+1 = x ∪ {x}，例如构造 7 = {0,1,2,3,4,5,6}。
- **公理 V（幂集）** 如果 A 是一个集合，那么 P(A) = {B : B ⊂ A} 也是一个集合。
- **公理 VI（无穷）** 存在一个集合 A，使得 0 ∈ A，且每当 x ∈ A 时 x+1 ∈ A。最小的这种集合是唯一的，称之为 ℕ = {0,1,2,3,…}。
- **公理 VII（选择公理）** 对任意集合 A，存在一个函数 c : P(A) − {∅} → A，使得对所有 B ⊂ A 都有 c(B) ∈ B。

## 公理的讨论

**公理 I（外延性）。** 为了有一个定义良好的论域，集合的元素本身也是集合。

公理 I 中有一个微妙之处：A = B 这个结论到底是什么意思？事实上，相等的概念是逻辑中的概念，而非集合论中的概念。它的意思是：对任何逻辑语句 P(x)，P(A) 与 P(B) 的答案相同。例如，如果 A = B 且 A ∈ Y，那么 B ∈ Y。

**公理 II（特称化）。** 例子：A ∩ B = {x ∈ A : x ∈ B}。A − B = {x ∈ A : x ∉ B}。ℝ − ℚ = 无理数；ℚ − ℝ = ∅。

- {x ∈ ℤ : ∃y ∈ ℤ, y+y = x} = 偶数集合。
- {x ∈ ℤ : x/n ∈ ℤ ∀n > 0} = {0}。
- {x ∈ ℤ : x² < 0} = ∅。

对于更高级的集合论，人们使用替换公理代替特称化公理；这允许构造基数如 ℵ_ω，但对大多数"主流"数学并非必需。

假设至少存在一个集合 A，我们可以构造

$$0 = \emptyset = \left\{x \in A : x \neq x\right\},$$

但除此之外不能确定别的什么（例如 A 可能就是 ∅）。

**塞维利亚的理发师；罗素悖论。** 如果 X = {A : A ∉ A}，那么 X ∈ X 吗？不存在"万有集"：给定一个集合 A，令 X = {B ∈ A : B ∉ B}。我们断言 X ∉ A。事实上，如果 X ∈ A，那么 X ∈ X 当且仅当 X ∉ X，矛盾。

经典悖论的一个解法——谁给塞维利亚的理发师刮胡子？——当然是理发师是个女人。在哥德尔-贝尔奈斯理论中，允许构造 X，但 X 不是一个集合；它被称为一个类。

**公理 III（配对）。** 由这条公理和空集 = 0，我们可以构造 {0,0} = {0}，称之为 1；也可以构造 {0,1}，称之为 2；但还不能构造 {0,1,2}。

**公理 IV（并集）。** 由这条公理和配对公理，我们可以构造 ∪{A,B} = A ∪ B。于是可以定义 x⁺ = x+1 = x ∪ {x}，例如构造 7 = {0,1,2,3,4,5,6}。

**交集。** 如果 A ≠ ∅，可以定义 ∩A = {x : ∀B ∈ A, x ∈ B}。由于 A 至少有一个元素 B₀，所以 ∩A ⊂ B₀，因此交集是一个集合。注意：∩∅ 是未定义的！

例子：∩{A} = A，∩{A,B} = A ∩ B。

**公理 V（幂集）。** 例子：X = {B ∈ P(52) : B 恰有 5 个元素} 是可能的扑克牌手数。|X| = 2,598,960。

帕斯卡三角形。{1,…,n} 的 k+1 元子集可以分成两类：包含 n 的和不包含 n 的。因此 C(n+1,k) = C(n,k) + C(n,k-1)。

**公理 VI（无穷）。** 我们已经通过集合论构造了自然数，进而可以构造实数、实函数等，一切都建立在空集之上。

另一个标准假设我们没有列出，就是外延公理，它断言不存在递减序列 … x₃ ∈ x₂ ∈ x₁。这意味着所有集合都建立在空集之上，我们永远不会遇到 x ∈ x 的无限循环。

一位和蔼的数学家叔叔问他的侄女："你知道的最大的数是多少？"侄女回答："168,000,000。"叔叔问："那 168,000,001 呢？"侄女回答："我已经很接近了，不是吗？"（哈伯德）

**继续推进。** 现在我们可以定义有序对：

$$\left(a,b\right) = \left\{\left\{a\right\}, \left\{a,b\right\}\right\}.$$

于是 (a,b) = (a',b') 当且仅当 a = a' 且 b = b'。然后可以定义两个集合的乘积：

$$A \times B = \left\{\left(a,b\right) : a \in A, b \in B\right\}.$$

注意 A × B ⊂ P(P(A ∪ B))，所以它是一个集合。

**关系。** A 和 B 之间的关系 R 是 A × B 的一个子集 R ⊂ A × B。它有定义域和值域。

一个关系可以可视化为一个有向图，顶点为 A ∪ B，当且仅当 (a,b) ∈ R 时有一条从 a 到 b 的边。

例子：等价关系是 A × A 中具有某些性质的子集。ℤ 上的关系 i < j。{1,2,…,10} 上的关系 b|a。

**函数。** 函数 f : A → B 是 A 和 B 之间的一个关系，使得对每个 a ∈ A，存在唯一的 b 使得 (a,b) ∈ f。我们记作 b = f(a)。函数也称为映射。

所有 f : A → B 的集合记作 B^A。为什么？3⁵ 有多少个元素？（答案：243。）

一个函数可以是单射的和/或满射的。如果两者皆是，则称为双射。

**映射的复合。** f ∘ g。如果 f : A → B 是双射，则存在唯一的映射 g : B → A 使得 g ∘ f(x) = x 对所有 x ∈ A 成立。

例子：f(n) = n² 在 ℕ 上是单射但在 ℤ 上不是单射。它在两者中都不是满射。函数 sin : ℝ → [−1,1] 是满射但不是单射。它的限制 sin : [−π/2, π/2] → [0,1] 是双射。它的另一个限制 sin : [0,1] → [−1,1] 是单射但不是满射。

**集合论作为一种编程语言。** 定义 ℕ 和 (a,b) 的要点不在于它们是自然的或标准的，而在于它们能行得通。换言之，集合论提供了一种非常简单的语言，数学的其余部分可以在其中被"实现"。

A × A 与 A² 之间有自然的双射。P(A) 与 2^A 之间有自然的双射。

**P(X) 作为代数。** 如果定义 A·B = A ∩ B，A + B = (A ∪ B) − (A ∩ B)，那么 P(X) 成为一个环。单位元是 ∅ 和 X。这个环不过是映射 f : X → ℤ/2 的环。

注意 A + A = 0。因此这个环也是域 𝔽₂ 上的代数。

令 χ : P(X) → 2^X 表示将 A 映到其指示函数 χ_A 的映射，χ_A 在 A 上为 1，其余地方为 0。

**函数、并集与交集。** 设 f : X → Y 是一个函数。令 f(A) = {f(a) : a ∈ A}。这样我们得到一个映射 f : P(X) → P(Y)。

这个映射是环同态吗？一般来说，f(A ∩ B) ≠ f(A) ∩ f(B)。我们只有 f(A ∩ B) ⊂ f(A) ∩ f(B)。但如果 f 是单射，则等号成立。不过我们总有 f(A ∪ B) = f(A) ∪ f(B)。

如果 f : A → B 是一个函数，对任意子集 X ⊂ B，定义 f⁻¹(X) = {a ∈ A : f(a) ∈ X}。于是有 f⁻¹ : P(B) → P(A)。这个映射保持交集和并集，例如 f⁻¹(X ∩ Y) = f⁻¹(X) ∩ f⁻¹(Y)。

滥用记号，也写 f⁻¹(b) 来表示 f⁻¹({b})。

**f⁻¹ 的普遍性。** f⁻¹ 保持集合论运算这一事实意味着，好的映射理论往往建立在 f⁻¹ 的性质而非 f 的性质之上。

例如，我们将看到，连续函数可以定义为满足 f⁻¹(U) 对每个开集 U 都是开集的函数。类似地，可测函数是满足 f⁻¹(U) 对每个开集 U 都是可测集的函数。

这种普遍性的另一个原因是函数自然地"拉回"。特别地，指示函数满足

$$\chi_A \circ f = f^*\left(\chi_A\right) = \chi_{f^{-1}\left(A\right)}.$$

这种拉回运算保持函数空间的代数结构。在微分拓扑中，我们发现微分形式也会被拉回，即 d(f*ω) = f*(dω)，等等。

**基数与选择公理。** 如果集合 A 和 B 之间存在双射，我们说它们具有相同的基数。我们将这一关系记作 |A| = |B|。它是一个等价关系。

**定理 2.1** |ℕ| ≠ |ℝ|。

**证明。** 假设 x(n) 是所有实数的一个列表，将它们的小数部分写成

$$\left\{x_n\right\} = 0.x_1\left(n\right)x_2\left(n\right)\dots$$

的十进制形式。现在任取一个数字序列 y_i，使得 y_n(n) ≠ x_n(n)。我们还可以安排 y_i 不重复。那么

$$y = 0.y_1y_2y_3\dots$$

与 x_n 在第 n 位上不同，所以它不在列表中。 ■

**定理 2.2（康托尔）** A 和 P(A) 不具有相同的基数。

**证明。** 给定 f : A → P(A)，令 B = {a : a ∉ f(a)}。假设 B = f(a)。那么 a ∈ B 当且仅当 a ∉ B。这是矛盾，所以 f 不存在。 ■

如果我们把 P(ℕ) ≅ 2^ℕ 看作二进制数字的序列 (a_i)，那么 |ℕ| ≠ |P(ℕ)| 的证明与对角线法几乎相同。

**推论 2.3** 存在多种不同大小的无穷。

**有限集。** 集合 A 是有限的，当且仅当存在双射 f : A → n（对某个 n ∈ ℕ）。也就是说，A 是有限的当且仅当 |A| = |n| 对某个 n ∈ ℕ。

**定理 2.4（鸽巢原理）** 如果 A 是有限的，那么任何单射 f : A → A 都是满射。

**证明。** 对 |A| = n 归纳。 ■

应用：对任意素数 p 和 a ≠ 0，存在整数 b 使得 ab = 1 mod p（即 b = 1/a）。证明：映射 b ↦ ab 在 ℤ/p 上是一一的，所以是满射。例子：1/10 = 12 mod 17；事实上 10 × 12 = 120 = 7 × 17 + 1。

**无限集。** 一个集合是无限的，当且仅当它不是有限的。

**定理 2.5** ℕ 是无限的。

**证明。** 否则，对某个 n，存在单射 ℕ → n，从而存在单射 n+1 → n。这与鸽巢原理矛盾。 ■

**公理 VII（选择公理）。** 对任意集合 A，存在一个函数 c : P(A) − {∅} → A，使得对所有 B ⊂ A 都有 c(B) ∈ B。

在具体情况下，可以找到显式的选择函数。对自然数，令 c(A) = min(A)。对有理数，我们可以取 A 中"最简单"的有理数 x = p/q，要求 q 最小、|p| 在 q 固定时最小、且 x ≥ 0 以打破平局。

**最小的无限集。** 这是选择公理的典型应用。

**定理 2.6** A 是无限的，当且仅当存在单射 f : ℕ → A。

**证明。** 如果 A 是有限的，那么 A 的任何子集都是有限的，所以不存在 ℕ 到 A 的单射。

现在假设 A 是无限的；我们来构造 f。取某个 a ∈ A。然后归纳定义 f(0) = a，f(n+1) = c(A − {f(0),…,f(n)})。所得映射由构造可知是单射。 ■

**康托尔的无穷定义。** 集合 A 是无限的，当且仅当存在映射 f : A → A，它是单射但不是满射。

证明使用选择公理：先将 ℕ 嵌入 A，然后在 ℕ 上使用 x ↦ x+1。

**希尔伯特旅馆。** 集合 ℕ（或任何无限集）可以用来说明希尔伯特旅馆。旅馆已满，但只要重新安排房客的住宿，就能腾出一间空房。

注意 ℕ 与 ℕ 的任何无限子集（如奇数集或平方数集）之间存在双射。

从前有一所大学，一长排办公室已经有些头重脚轻：教授们只能占用编号为 1,4,9,16,…,n²,… 的办公室，因为其余的被院长们占了。教授们震怒，要求每位教授配自己的院长，其余的院长被解雇。n 号办公室的院长被分配给 n² 号房间的教授，现在院长们完全成为教授的私人助理。

没有人被解雇。事实上，16,81,256 号办公室的教授仍然没有助理，于是更多的院长被雇用了。

**选择公理的其他应用。** 每个向量空间都有基。哈恩-巴拿赫定理。每个集合都可以被良序化。G/H 的陪集代表的选取。不可测集的存在性。

**巴拿赫-塔尔斯基悖论。** 作为选择公理的推论，你可以把一个葡萄柚切成 5 块，然后通过刚体运动重新拼成 2 个葡萄柚。（现在你知道你做得太过分了。）

**相对大小。** 自然地，如果存在从 A 到 B 的满射，我们说 |A| ≥ |B|。但同样自然地要求存在从 B 到 A 的单射。上面的结果用于证明这两个定义等价。

小提示：如果 |B| = 0，满射定义不适用。

我们说 |A| ≤ |B|，如果

1. 存在单射 f : A → B；或
2. 存在满射 g : B → A，或 A = ∅。

**定理 2.7** (1) 和 (2) 等价。

**证明。** 给定单射 f，我们从 f⁻¹ 得到从 f(A) 回到 A 的满射，只要 A ≠ ∅，就可以将其扩展为 B 其余部分上的常值映射。反过来，使用选择公理，取 f 为 g 的一个截面，即 f(a) = c(g⁻¹({a}))。 ■

**定理 2.8（施罗德-伯恩斯坦）** 如果 |A| ≤ |B| 且 |B| ≤ |A|，那么 |A| = |B|。

**证明。** 假设 A 和 B 不交——如有必要，总可以将 A、B 替换为 A × {0}、B × {1} 来实现。

假设我们有单射 f : A → B 和 g : B → A。于是得到单射

$$F = f \cup g : A \cup B \to A \cup B.$$

为阐明证明，称 F(x) 为 x 的孩子，x 为 F(x) 的父母。由于 F 是单射，一个孩子只能有一个父母，而 A ∪ B 的每个元素都是父母。但有些父母不是任何人的孩子；我们称之为"教父"。

对任何 x ∈ A ∪ B，要么 x 来自某个唯一的教父（可能就是 x 自己），要么 x 没有教父；它有无穷长的祖先链（或者 x 来自自身）。

现在将 A 分成三部分 A₀、A_A 和 A_B。A₀ 是没有教父的元素 x ∈ A；A_A 由那些教父在 A 中的 x 组成；A_B 是那些教父在 B 中的 x。类似地定义 B₀、B_A、B_B。

通过将 a 映到其孩子 F(a)，存在双射 A₀ ↔ B₀。它是单射因为 F 是单射，它是满射因为每个 x ∈ B₀ 都有父母，而父母必在 A₀ 中。

通过将每个 a ∈ A_A 映到其孩子 F(a)，存在双射 A_A ↔ B_A。逆映射将孩子映回父母。在 B_A 中没有教父，所以逆映射是良定义的。

类似地，存在双射 A_B ↔ B_B，将 a ∈ A 映到其在 B_B 中的父母。将这三个双射合在一起，即得 |A| = |B|。 ■

**可数集。** 如果 |A| ≤ |ℕ|，我们说 A 是可数的。有限集是可数的。

**定理 2.9** 如果 A 是可数无限的，那么 |A| = |ℕ|。

**证明。** 无限蕴含 |ℕ| ≤ |A|，可数蕴含 |A| ≤ |ℕ|；应用施罗德-伯恩斯坦定理。 ■

**定理 2.10** ℕ² 是可数的。

**证明。** 定义双射 f : ℕ → ℕ²，令 f(n) = (a,b)，其中 n+1 = 2^a(2b+1)。 ■

**推论 2.11** 可数个可数集的并集是可数的。

**证明。** 如果 X = ∪A_i，可以将 A_i 的第 j 个元素映到 (i,j) ∈ ℕ × ℕ。 ■

**例子。**

1. 可以用语言描述的事物的集合是可数的。因此大多数实数没有名字。
2. 整数 ℤ 可以由 2 × ℕ 构造；满足 |ℤ| = |ℕ|。
3. 有理数 ℚ = ℤ × ℤ*/~，其中 (a,b) ~ (c,d) 当且仅当 ad − bc = 0。因此 ℚ 是可数的。
4. 多项式环 ℤ[x] 是可数的。

**推论 2.12** 大多数实数是超越数。

**警告。** 可数个可数集的和是可数的，但乘积不然。事实上，2^ℕ 是有限集的可数乘积，但它自然同构于 P(ℕ)。

**定理 2.13** |ℝ| = |P(ℕ)|。

**证明。** 可以为每个子集 A ⊂ ℕ 关联一个以二进制定义的唯一实数

$$x_A = x_0.x_1x_2x_3\dots = \sum_{n\in A} 2^{-n},$$

其中 x_n = 1 如果 n ∈ A，否则为 0。反过来，实数 x 由集合

$$A_x = \left\{y \in \mathbb{Q} : y < x\right\} \subset \mathbb{Q}$$

唯一确定。因此 |P(ℕ)| ≤ |ℝ| ≤ |P(ℚ)| = |P(ℕ)|。 ■

**定理 2.14** |ℝ^ℝ| = |P(P(ℕ))|。因此 ℝ 上的函数代表第三种无穷。

**证明。** 首先注意我们有简单的不等式：

$$\left|P\left(P\left(\mathbb{N}\right)\right)\right| = \left|P\left(\mathbb{R}\right)\right| = \left|2^{\mathbb{R}}\right| \leq \left|\mathbb{R}^{\mathbb{R}}\right|.$$

另一方面，我们可以通过交错十进制数字构造单射 i : ℝ² → ℝ。由于函数 f : ℝ → ℝ 是一种特殊的关系 f ⊂ ℝ × ℝ，于是有：

$$\left|\mathbb{R}^{\mathbb{R}}\right| \leq \left|P\left(\mathbb{R}^2\right)\right| = \left|P\left(\mathbb{R}\right)\right|,$$

由施罗德-伯恩斯坦定理，|ℝ^ℝ| = |P(P(ℕ))|。 ■

另一种理解 |ℝ²| = |ℝ| 的方式是注意到 |ℕ × 2| = |ℕ|，因此

$$\left|\mathbb{R}^2\right| = \left|P\left(\mathbb{N}\right) \times P\left(\mathbb{N}\right)\right| = \left|P\left(\mathbb{N} \times 2\right)\right| = \left|P\left(\mathbb{N}\right)\right| = \left|\mathbb{R}\right|.$$

**连续统假设。** 使用选择公理，可以证明对任意两个集合 A 和 B，要么 |A| ≤ |B|，要么 |B| ≤ |A|。

是否存在集合 A 使得 |ℕ| < |A| < |ℝ|？现在已知这个问题**不能**用集合论公理回答（假设这些公理本身是一致的）。一些逻辑学家认为连续统假设显然为假（科恩、伍丁），另一些人则认为它必为真（伍德林）。
