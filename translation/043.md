2. 只要 $s < t$，就有 $A_s \subset \text{int}(A_t)$。

3. 只要 $s < 1$，就有 $A_s \subset X - B$。

完成后，我们定义 $f : X \to [0, 1]$：

$$f(x) = \inf\{s : x \in A_s\}.$$

由上面的条件我们得到 $f|_A = 0$，$f|_B = 1$。关于连续性，首先注意到

$$f^{-1}((-\infty, a)) = \{x : f(x) < a\} = \bigcup_{s<a} A_s = \bigcup_{s<a} \text{int}(A_s)$$

是开集的并集，因此是开的。类似地

$$f^{-1}((b, +\infty)) = \{x : f(x) > b\} = \bigcup_{s>b} (X - A_s)$$

也是开的。由于这两类区间生成实数上的拓扑，$f$ 连续。 ∎

**注。**尽管 $f|_A = 0$，我们未必有 $f^{-1}(0) = A$，对 $B$ 类似。

**极大理想。**乌雷松引理的一个重要推论是：如果 $K$ 是紧豪斯多夫空间，那么 $C(K)$ 中的函数分离 $K$ 的点。因此任意代数同态 $\varphi : C(K) \to \mathbb{R}$ 都来自某点的赋值（练习）。

**定理7.3的证明。**首先对可数基中每一对满足 $B \subset B'$ 的元素 $B, B'$，构造一个函数 $f : X \to [0, 1]$，它在 $B$ 上为 1，在 $B'$ 外为 0。令这样的可数函数集为 $(f_1, f_2, \dots)$，令

$$\varphi : X \to [0, 1]^\mathbb{N}$$

为重言式嵌入：

$$\varphi(x) = (f_1(x), f_2(x), \dots).$$

我们给目标赋乘积拓扑。希尔伯特立方体 $[0, 1]^\mathbb{N}$ 当然是可度量化的。因此完成证明只需证明 $\varphi$ 是嵌入。
