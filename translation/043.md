2. 只要 $s < t$，就有 $A_s \subset \text{int}\left(A_t\right)$。

3. 只要 $s < 1$，就有 $A_s \subset X - B$。

完成后，我们定义 $f : X \to \left[0, 1\right]$：

$$f\left(x\right) = \inf\left\{s : x \in A_s\right\}.$$

由上面的条件我们得到 $f|_A = 0$，$f|_B = 1$。关于连续性，首先注意到

$$f^{-1}\left(\left(-\infty, a\right)\right) = \left\{x : f\left(x\right) < a\right\} = \bigcup_{s<a} A_s = \bigcup_{s<a} \text{int}\left(A_s\right)$$

是开集的并集，因此是开的。类似地

$$f^{-1}\left(\left(b, +\infty\right)\right) = \left\{x : f\left(x\right) > b\right\} = \bigcup_{s>b} \left(X - A_s\right)$$

也是开的。由于这两类区间生成实数上的拓扑，$f$ 连续。 ∎

**注。**尽管 $f|_A = 0$，我们未必有 $f^{-1}\left(0\right) = A$，对 $B$ 类似。

**极大理想。**乌雷松引理的一个重要推论是：如果 $K$ 是紧豪斯多夫空间，那么 $C\left(K\right)$ 中的函数分离 $K$ 的点。因此任意代数同态 $\varphi : C\left(K\right) \to \mathbb{R}$ 都来自某点的赋值（练习）。

**定理7.3的证明。**首先对可数基中每一对满足 $B \subset B'$ 的元素 $B, B'$，构造一个函数 $f : X \to \left[0, 1\right]$，它在 $B$ 上为 1，在 $B'$ 外为 0。令这样的可数函数集为 $\left(f_1, f_2, \dots\right)$，令

$$\varphi : X \to \left[0, 1\right]^\mathbb{N}$$

为重言式嵌入：

$$\varphi\left(x\right) = \left(f_1\left(x\right), f_2\left(x\right), \dots\right).$$

我们给目标赋乘积拓扑。希尔伯特立方体 $\left[0, 1\right]^\mathbb{N}$ 当然是可度量化的。因此完成证明只需证明 $\varphi$ 是嵌入。
