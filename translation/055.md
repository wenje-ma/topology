由 $p(x) = x \pmod 1$ 给出。见图5。

在这个情形下，容易理解路径提升。也就是说，如果 $f([0, 1])$ 完全落在 $S^1$ 中的一个区间 $I$ 内，那么 $p^{-1}$ 沿 $I$ 有单值分支，我们只需令 $F = p^{-1} \circ f$。一旦指定 $F(0)$，分支就唯一确定。由一致连续性，任意路径 $f : [0, 1] \to S^1$ 都可以拆成这种类型的小段；逐段提升，就得到 $f$ 的提升。

**路径与环路空间。**路径空间 $P_b(B)$ 由所有 $f : ([0, 1], 0) \to (B, b)$ 组成。如果 $B$ 是度量空间，那么 $P_b(B)$ 也是，度量为

$$D(f, g) = \sup_t d(f(t), g(t)).$$

事实上，$P_b(B)$ 是 $C([0, 1], B)$ 的闭子空间。

类似地，如果再施加条件 $f(1) = b$，我们得到环路空间 $\Omega_b(B)$。

**提升的连续性。**现在考虑圆的情形。路径提升定义了自然映射

$$L : P_0(S^1) \to P_0(\mathbb{R}).$$

**定理10.4** 路径提升是连续的。

*证明。*我们断言如果 $D(f, g) < 1/100$，那么 $D(F, G) = d(f, g)$。事实上，对每个 $t \in [0, 1]$，要么 $d(F(t), G(t)) = d(f(t), g(t))$，要么 $d(F(t), G(t)) \geq 1/2$。两个集合都是闭的，第一个包含 $t = 0$，所以它包含所有 $t \in [0, 1]$。因此路径提升实际上是从 $P_0(S^1)$ 到 $P_0(\mathbb{R})$ 的局部等距。 ∎
