对于实值函数，可以取 $\cos f(x, y)$ 或 $\sin f(x, y)$。同样的构造对任意 $f(x, y) = F(\theta)$ 都适用，只要 $F : S^1 \to \mathbb{R}$ 连续，$F(\theta) = 0$（$\theta = 0, \pi/2, \pi, 3\pi/2$），且 $F(\theta)$ 不恒为零。

"经典"反例正比于

$$f(x, y) = \sin(2\theta) = \frac{\operatorname{Im} z^2}{|z|^2} = \frac{2xy}{x^2 + y^2}.$$

更一般地，如果我们取 $x, y$ 中任意两个同次齐次多项式 $P$ 和 $Q$，且对 $(x, y) \neq 0$ 有 $Q(x, y) \neq 0$，那么我们可以令

$$f(x, y) = \frac{P(x, y)}{Q(x, y)}$$

（在原点之外）。然后，如果 $P(1, 0) = P(0, 1) = 0$，我们可以令 $f(0, 0) = 0$ 延拓 $f$，得到一个关于 $x$ 和 $y$ 分别连续的函数。最后，如果 $P(x, y)$ 不恒为零，$f(x, y)$ 将不连续。

**正规性。**一旦点是闭的，我们就可以施加更强的正规性条件（$T_4$）：任意两个不相交的闭集 $A, B \subset X$ 可以被不相交的开集 $U \supset A$、$V \supset B$ 所包裹。我们稍后将看到，这个强有力的条件保证存在连续函数 $f : X \to \mathbb{R}$ 使得 $f|_A = 1$ 且 $f|_B = 0$。特别地，$C(X)$ 是非平凡的（只要 $|X| > 1$）。

**无穷乘积。**令 $X_i$ 是以 $i \in I$ 为指标的一族拓扑空间。它们的乘积 $X = \prod X_i$ 由映射 $x : I \to \bigcup X_i$ 构成，满足 $x_i \in X_i$。

$X$ 上的乘积拓扑由开集基

$$U = \prod U_i$$

定义，其中每个 $U_i \subset X_i$ 是开集，且除有限个 $i$ 外 $U_i = X_i$。（验证这些基元素满足 $B_1 \cap B_2 \supset B_3$。）

**定理3.7** 映射 $f : Z \to \prod X_i$ 是连续的，当且仅当它的每个坐标 $f_i : Z \to X_i$ 都连续。

*例子。*令 $2 = \{0, 1\}$ 赋离散拓扑。那么 $2^\mathbb{N} \cong \mathcal{P}(\mathbb{N})$ 成为一个拓扑空间。$\mathbb{N}$ 的两个子集在它们与 $[0, N]$ 的交集对大 $N$ 相同时接近。
