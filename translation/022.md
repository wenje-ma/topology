经典的康托集 $K \subset [0, 1]$ 同胚于 $2^\mathbb{N}$，因此提供了一种可视化所有 $\mathbb{N}$ 的子集的方式。

结果表明，对任意一列非空有限集 $X_i$（每个赋离散拓扑），空间 $\prod X_i$ 同胚于康托集。即使对 $3^\mathbb{N}$ 这已经很难看出了。

**逐点收敛。**固定任意集合 $S$，令

$$X = \mathbb{R}^S = \{\text{所有函数 } f : S \to \mathbb{R}\}$$

赋乘积拓扑。那么序列 $f_n \in X$ 收敛到 $g$ 当且仅当对所有 $s \in S$ 有 $f_n(s) \to g(s)$。因此乘积拓扑在 $X = A^B$ 的情形有时称为逐点收敛拓扑。

**希尔伯特立方体。**无穷乘积的另一个好例子是 $X = [0, 1]^\mathbb{N}$。这就是所有序列 $(x_i)$（$0 \leq x_i \leq 1$）的空间。拓扑由一个好的度量诱导，例如

$$d(x, y) = \max |x_n - y_n| / 2^n.$$

**盒拓扑。**$X = \prod X_i$ 上的盒拓扑定义为：使用开集的所有乘积 $\prod U_i$ 构成拓扑的基。

这个拓扑非常强（即它有很多开集），因此进入乘积的连续映射非常少。

*练习。*$[0, 1]$ 到 $[0, 1]^\mathbb{N}$ 的对角映射 $D$ 在乘积拓扑中连续，但在盒拓扑中不连续。

（*证明：*每个因子 $D_i : [0, 1] \to [0, 1]$ 就是恒等映射，是连续的，所以乘积拓扑没问题。但在盒拓扑中，对任意 $x \in [0, 1]$ 我们可以找到一列包含 $x$ 的开集 $U_i$ 嵌套收敛到它。那么 $D^{-1}(\prod U_i) = \bigcap U_i = \{x\}$ 不是开集，所以 $D$ 不连续。）

**拓扑群。**一个拓扑群是一个集合 $G$，配备连续的乘积映射和逆映射 $G \times G \to G$ 和 $G \to G$，满足通常的群公理。

最基本的拓扑群是 $(\mathbb{R}, +)$ 和 $(\mathbb{R}^*, \cdot)$。它们是群这一事实表明 $C(X)$ 是一个代数。取逆连续这一事实表明，只要 $f$ 没有零点，$1/f \in C(X)$。

其他例子包括矩阵群 $GL_n(\mathbb{R})$，它可以通过矩阵视为 $\mathbb{R}^{n^2}$ 的一个开子集。克莱姆法则表明取逆是连续的。

这里是一个关于拓扑群的典型定理。
