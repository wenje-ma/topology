图9. 证明在安全地下通道处 $ac = cb$。

*例子：*三叶结群。对一个所有交叉都安全的三叶结，群为

$$G(K) = \langle a, b, c : ab = bc,\ bc = ca,\ ca = ab\rangle.$$

**将 $G(K)$ 映到 $\mathbb{Z}$。**这很容易：定义 $\varphi(a) = \varphi(b) = \varphi(c) = 1$。它对每个纽结群都有效。

**经线。**注意对纽结，所有生成元在 $\pi_1(K)$ 中共轭。这个共轭类由经线给出，即绕纽结的小环路。

**将 $G(K)$ 映到 $S_3$。**注意 $S_3$ 有 3 个对换，记作 $A, B, C$；它们都是奇置换。它们必须满足 $AB = CA$，因为 $ABA$ 是奇的，它不能是 $A$（否则 $A = B$），也不能是 $B$（否则 $S_3$ 交换）。把 $(a, b, c)$ 映到 $(A, B, C)$，我们看到 $G$ 承认 $S_3$ 为商！

推论：三叶结真的是打结的。

**三染色。**纽结投影（不带定向）的三染色是给每条 strand 关联三种颜色之一（比如 R、G、B），满足：在每个交叉处要么三种颜色全相同，要么全不同；且所有颜色都被使用。

**定理15.6** 纽结的三染色与满同态 $\varphi : G(K) \to S_3$ 一一对应。

*证明。*令 $A, B, C$ 为 $S_3$ 中的三个对换如前。由于 $G(K)$ 的生成元对应弧，我们可以用三种颜色在生成元上定义映射 $\varphi : G(K) \to S_3$。那么三染色条件表明 $G(K)$ 中的每个关系都满足。因此我们可以把颜色 $A$ 的 strand 的生成元映到对换 $a$，等等。由于至少用了两种颜色，我们得到满射。
