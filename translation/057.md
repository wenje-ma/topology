换个角度，假设 $f : S^1 \to S^1$。通过路径提升，我们可以找到映射 $F : \mathbb{R} \to \mathbb{R}$ 使得 $p\left(F\left(x\right)\right) = f\left(p\left(x\right)\right)$。这个映射满足

$$F\left(x+1\right) = F\left(x\right) + \deg\left(f\right).$$

显式地，我们可以把 $f$ 看作从 $\left[0, 1\right]$ 到 $S^1$ 的映射，然后把它提升为映射 $F : \left[0, 1\right] \to \left[x, x + \deg\left(f\right)\right]$（对某个 $x$）。然后我们把 $F$ 周期延拓到 $\mathbb{R}$。

**度数与原像。**由于 $S^1$ 以 $\mathbb{R}$ 为模型，谈论光滑或分段线性映射 $f : S^1 \to S^1$ 是有意义的。例如，对任意光滑映射 $f : S^1 \to S^1$，$f'\left(x\right)$ 有意义，因为 $f$ 的任意提升的导数 $F'\left(x\right)$ 在 $x \mapsto x + n$ 下不变。

现在令 $\deg\left(f, x\right) = \operatorname{sign} f'\left(x\right) = -1, 0$ 或 $1$。如果 $f'\left(x\right)$ 不存在，令 $\deg\left(f, x\right) = 0$。$f$ 的奇点是满足 $\deg\left(f, x\right) = 0$ 的 $x$；它们的像就是奇异值。

**定理10.7** 令 $f : S^1 \to S^1$ 为光滑或 PL 映射，假设 $y \in S^1$ 不是 $f$ 的奇异值。那么 $f^{-1}\left(y\right)$ 有限，且 $\deg\left(f\right) = \sum_{f\left(x\right)=y} \deg\left(f, x\right)$。

**一般路径提升。**同样的结果对一般覆盖空间成立。首先，如我们所见，任意路径 $f : \left[0, 1\right] \to B$（$b_0 = f\left(0\right) = p\left(e_0\right)$）有唯一提升 $F$ 满足 $F\left(0\right) = e_0$。更一般地，给定

$$f : \left[0, 1\right]^n \to B$$

满足 $f\left(0, \dots, 0\right) = b_0 = p\left(e_0\right)$，存在唯一提升

$$F : \left[0, 1\right]^n \to E$$

满足 $F\left(0, \dots, 0\right) = e_0$。换句话说我们有：

**定理10.8** 任意映射 $f : \left[0, 1\right]^n \to \left(B, b\right)$ 有唯一提升 $F : \left[0, 1\right]^n \to \left(E, e\right)$。
