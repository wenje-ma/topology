换个角度，假设 $f : S^1 \to S^1$。通过路径提升，我们可以找到映射 $F : \mathbb{R} \to \mathbb{R}$ 使得 $p(F(x)) = f(p(x))$。这个映射满足

$$F(x+1) = F(x) + \deg(f).$$

显式地，我们可以把 $f$ 看作从 $[0, 1]$ 到 $S^1$ 的映射，然后把它提升为映射 $F : [0, 1] \to [x, x + \deg(f)]$（对某个 $x$）。然后我们把 $F$ 周期延拓到 $\mathbb{R}$。

**度数与原像。**由于 $S^1$ 以 $\mathbb{R}$ 为模型，谈论光滑或分段线性映射 $f : S^1 \to S^1$ 是有意义的。例如，对任意光滑映射 $f : S^1 \to S^1$，$f'(x)$ 有意义，因为 $f$ 的任意提升的导数 $F'(x)$ 在 $x \mapsto x + n$ 下不变。

现在令 $\deg(f, x) = \operatorname{sign} f'(x) = -1, 0$ 或 $1$。如果 $f'(x)$ 不存在，令 $\deg(f, x) = 0$。$f$ 的奇点是满足 $\deg(f, x) = 0$ 的 $x$；它们的像就是奇异值。

**定理10.7** 令 $f : S^1 \to S^1$ 为光滑或 PL 映射，假设 $y \in S^1$ 不是 $f$ 的奇异值。那么 $f^{-1}(y)$ 有限，且 $\deg(f) = \sum_{f(x)=y} \deg(f, x)$。

$$f : [0, 1]^n \to B$$

满足 $f(0, \dots, 0) = b_0 = p(e_0)$，存在唯一提升

$$F : [0, 1]^n \to E$$

满足 $F(0, \dots, 0) = e_0$。换句话说我们有：

**定理10.8** 任意映射 $f : [0, 1]^n \to (B, b)$ 有唯一提升 $F : [0, 1]^n \to (E, e)$。
