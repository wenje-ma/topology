**函数。**函数 $f : A \to B$ 是 $A$ 与 $B$ 之间的关系，使得对每个 $a \in A$，存在唯一的 $b$ 满足 $\left(a, b\right) \in f$。我们记作 $b = f\left(a\right)$。函数也称为映射。

所有 $f : A \to B$ 构成的集合记作 $B^A$。为什么？$3^5$ 有多少个元素？（答案：243。）

一个函数可以是单射的和/或满射的。如果两者都是，则称为双射。

**映射的复合：**$f \circ g$。如果 $f : A \to B$ 是双射，那么存在唯一的映射 $g : B \to A$，使得对所有 $x \in A$ 都有 $g \circ f\left(x\right) = x$。

例子：$f\left(n\right) = n^2$ 在 $\mathbb{N}$ 上是单射，但在 $\mathbb{Z}$ 上不是。在两种情况下都不是满射。函数 $\sin : \mathbb{R} \to \left[-1, 1\right]$ 是满射但不是单射。它的限制 $\sin : \left[-\pi/2, \pi/2\right] \to \left[0, 1\right]$ 是双射。它的另一个限制 $\sin : \left[0, 1\right] \to \left[-1, 1\right]$ 是单射但不是满射。

**集合论作为编程语言。**定义 $\mathbb{N}$ 和 $\left(a, b\right)$ 的要点不在于它们是自然的或标准的，而在于它们是可行的。换句话说，集合论提供了一种非常简单的语言，数学的其余部分都可以在其中实现。

$A \times A$ 与 $A^2$ 之间存在自然双射。

$\mathcal{P}\left(A\right)$ 与 $2^A$ 之间存在自然双射。

**$\mathcal{P}\left(X\right)$ 作为代数。**如果我们定义 $A \cdot B = A \cap B$，$A + B = \left(A \cup B\right) - \left(A \cap B\right)$，那么 $\mathcal{P}\left(X\right)$ 成为一个环。单位元是 $\emptyset$ 和 $X$。这个环不过是映射 $f : X \to \mathbb{Z}/2$ 的环。

注意 $A + A = 0$。因此这个环也是域 $\mathbb{F}_2$ 上的代数。

我们令

$$\chi : \mathcal{P}\left(X\right) \to 2^X$$

表示将 $A$ 映射到其示性函数 $\chi_A$ 的映射，$\chi_A$ 在 $A$ 上取值 1，其余地方取值 0。

**函数、并集与交集。**设 $f : X \to Y$ 是一个函数。我们令 $f\left(A\right) = \left\{f\left(a\right) : a \in A\right\}$。这样我们得到一个映射 $f : \mathcal{P}\left(X\right) \to \mathcal{P}\left(Y\right)$。

这个映射是环同态吗？

一般来说，$f\left(A \cap B\right) \neq f\left(A\right) \cap f\left(B\right)$。我们只有 $f\left(A \cap B\right) \subset f\left(A\right) \cap f\left(B\right)$。然而，如果 $f$ 是单射，则等号成立。不过我们总有 $f\left(A \cup B\right) = f\left(A\right) \cup f\left(B\right)$。

如果 $f : A \to B$ 是一个函数，对任意子集 $X \subset B$，我们定义 $f^{-1}\left(X\right) = \left\{a \in A : f\left(a\right) \in X\right\}$。因此我们有 $f^{-1} : \mathcal{P}\left(B\right) \to \mathcal{P}\left(A\right)$。这个映射保持交集和并集：例如 $f^{-1}\left(X \cap Y\right) = f^{-1}\left(X\right) \cap f^{-1}\left(Y\right)$。

滥用记号，人们也把 $f^{-1}\left(\left\{b\right\}\right)$ 记作 $f^{-1}\left(b\right)$。
